########################################################## 
#Building the initial stuctures of Ti models using Atomsk
##########################################################

# Experimental lattice parameters at room temperature of crystalline HCP Ti are used.
# x-axis, y-axis, and z-axis are aligned to <10-10> <1-210>, and <0001> crystallographic orientations, respectively.
# First, an orthogonal HCP supercell is construted. Then different simulation boxes are created by replicating this supercell Nx x Ny x Nz times.
# Stucture file is saved as LAMMPS data file ready to be used in the input file. 


# Run this command line in your terminal by choosing the appropriate replication:
atomsk --create hcp 2.95 4.68 Ti orient [10-10] [1-210] [0001] -duplicate N N N TiN.lmp
